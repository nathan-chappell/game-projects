# Original orbit attack — hard version

Saved before reducing the normal fourth attack’s snowball count.

- `LittleLantern-Orbit-Hard.html` is a complete playable snapshot of the game with the original 18-snowball attack. Use Shift during earlier enemy attacks to reach it quickly.
- `battle-orbit.js` preserves the original source and settings: six inner snowballs, twelve outer snowballs, the rotating 50-damage cube, 10-damage snowballs, and the bouncing box.

The current source also retains this pattern through `createOrbitAttack('hard')`. It is reserved for future use and is not in the normal attack cycle. Normal play uses four inner snowballs and six outer snowballs.
